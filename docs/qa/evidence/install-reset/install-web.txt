6. Production with a key, wrong key and throttle
----------------------------------------------------------------
A second server used the same production wrapper and set ECO_INSTALL_KEY
to a 37-character evidence value (not recorded here). The key is read from
the environment, never from the page.
One wrong key (fresh browser session): the form re-renders with
  "The install key does not match INSTALL_KEY. 4 attempts left."
  and the key row fails. No database write.
Five wrong keys in the same session: the page then shows
  "Too many install-key attempts. Wait 15 minutes before trying again."
  and the key row still fails. The throttle is session-scoped (5 attempts
  per 15 minutes); a correct key clears it.
After all attempts: 0 tables, no storage/install.lock.
No password, key or DSN appears in either page.
